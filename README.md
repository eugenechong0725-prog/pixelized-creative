# Pixelized Creative — Sample Landing Page

One-page marketing sample for **Pixelized Creative**, a Malaysian printing and creative business.

Built to impress the client with design direction and conversion flow — WhatsApp quotation CTAs throughout, no backend.

## Stack

- Next.js (App Router)
- React
- Tailwind CSS
- TypeScript

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## WhatsApp

All enquiry CTAs open:

`https://wa.me/601126208959`

with pre-filled messages based on the service or offer clicked.
